new Game(initialState)
   │
   └─ constructor: this.field = ..., this.score = 0, this.status = 'idle'
      (плюс: запам'ятати initialState окремо, для restart)


start()
   │
   ├─ this.status = 'playing'
   └─ викликає ──► addRandomTile()   [додає 1-2 числа на поле]


addRandomTile()   ← "приватна" допоміжна функція, не з README-списку,
                     ти сам її придумуєш і викликаєш зсередини
   │
   ├─ знаходить порожні клітинки в this.field
   ├─ обирає випадкову
   └─ ставить туди 2 (90%) або 4 (10%)


moveLeft() / moveRight() / moveUp() / moveDown()
   │
   ├─ зберігає копію поля "до ходу" (для порівняння)
   ├─ викликає ──► slideAndMergeRow() для кожного рядка/стовпця
   │                [ЄДИНА функція, яка реально рахує злиття,
   │                 інші 3 напрямки лише "розвертають" поле
   │                 до/після виклику цієї функції]
   ├─ порівнює поле "до" і "після" → чи був рух?
   ├─ якщо був рух:
   │     ├─ this.score += сума об'єднаних чисел
   │     ├─ викликає ──► addRandomTile()
   │     ├─ викликає ──► checkWin()   → якщо є 2048, this.status = 'win'
   │     └─ викликає ──► checkGameOver() → якщо нема ходів, this.status = 'lose'
   └─ якщо руху не було: нічого не змінюється


slideAndMergeRow(row)   ← ще одна приватна допоміжна функція
   │
   ├─ прибрати нулі (стиснути числа до краю)
   ├─ об'єднати сусідні однакові → подвоїти, позначити "вже об'єднана"
   └─ ще раз прибрати нулі
   └─ повертає новий рядок + суму набраних очок за цей рядок


checkWin()   ← допоміжна
   └─ перевіряє this.field: чи є десь 2048?


checkGameOver()   ← допоміжна
   └─ перевіряє: чи є порожні клітинки АБО чи можна щось об'єднати?
       якщо ні на те, ні на те — гра закінчена


restart()
   │
   ├─ this.field = (те саме початкове поле, що запам'ятали в конструкторі)
   ├─ this.score = 0
   └─ this.status = 'idle' (не 'playing'! бо це те саме, що щойно створений об'єкт)


getState() / getScore() / getStatus()
   │
   └─ просто повертають this.field / this.score / this.status
      (ти це вже зробив ✅)
